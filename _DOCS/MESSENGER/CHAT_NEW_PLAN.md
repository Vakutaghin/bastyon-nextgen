## Известные проблемы и решения (History)
- **Decryption Error (Invalid character)**: Исправлено конвертацией `Uint8Array` в `Buffer` перед `toString('hex')` при генерации ключей. (BN.js требовал hex-строку).
- **Event.getId is not a function**: Исправлено внедрением безопасных хелперов `getEventId` в `store.ts`.
- **AES-SIV: ciphertext verification failure**: Исправлено. Внедрена улучшенная логика извлечения `block height`, стабильная сортировка пользователей по `dbId` и механизм fallback для дешифровки (проверка разных форматов AD/IV).
- **Linter Errors**: Исправлен экспорт синглтона `matrixService` и типизация событий.
- **Matrix login failed (Bad parameter / 403 Forbidden)**: Восстановлена рабочая логика из коммита 3a15627. Логин нормализует адрес (hex → base58 при необходимости), формирует `user` как hex‑адрес в lower‑case и выполняет `m.login.password` с double‑SHA256 от hex‑строки приватного ключа, затем при необходимости выполняет регистрацию через `m.login.dummy`.
