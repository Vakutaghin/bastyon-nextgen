# Ручные проверки на живых сборках

Что код и тесты уже покрывают, но что проверяется только вживую: нужен аккаунт с балансом,
сборка под платформу или второй клиент. Собрано из аудита 2026-09 при его закрытии
(`git show efe6cf3:_docs-todo/APP_AUDIT_2026-09.md`, пометки `[~ needs-live]`) и работы после.
Проверил — вычеркни строку; нашёл баг — заведи задачу.

## С аккаунтом (веб или десктоп)

- [ ] Вход по мнемонике: поле скрыто, «глаз» работает. Вход по WIF (ключ на `5`/`6`/`2`) пускает в тот же аккаунт, что и мнемоника.
- [ ] Регистрация: отмена поверх живой сессии возвращает к ней; перезагрузка посреди регистрации — сид показан после подтверждения; «Обновить капчу» даёт картинку, а не пустое поле.
- [ ] Регистрация, занятое имя (отзыв тестера с Windows 10: «имя занято» не показывалось, после капчи ошибка без повтора, потом `iplimit`): подсказка «имя занято» появляется под полем, пока имя набирают, до капчи. Если сеть всё же отвергла имя после капчи — модалка открывается снова с причиной словами, повтор с другим именем идёт без капчи и без новых монет; после перезапуска та же модалка и пункт «Завершить регистрацию» в меню аватара. `iplimit` — текст про лимит по IP, а не код.
- [ ] Смена аккаунта A→B: подписки, чёрный список, уведомления, избранное и `/limits` — от B; WS-пуши приходят по B.
- [ ] Публикация: пост появляется без F5; при медленной ноде нет дубля (одна транзакция); правка видео-поста сохраняет видео, видимость и язык; удаление убирает пост из ленты.
- [ ] Комментарии: ответ на ответ виден в ветке; счётчик «Осталось N символов» склоняется.
- [ ] Оценки: отредактированный пост оценивается; свой пост оценить нельзя; 1★ показывается как низкая оценка.
- [ ] Уведомления приходят до первого открытия выпадашки и переживают перезапуск; бейдж гаснет после закрытия; тумблеры типов влияют на список.
- [ ] «Сначала лучшее» с окнами сутки / 3 дня / неделя; обрыв сети на догрузке ленты — посты остаются, под ними ошибка и «Повторить».
- [ ] Кошелёк: перевод обновляет баланс и показывает реальную комиссию; bitcoin-адрес отвергается понятным текстом; история не зависит от ноды, закреплённой в эксплорере.
- [ ] Чёрный список убирает автора из ленты, бустов и рекомендаций и глушит переписку.
- [ ] Профиль: смена имени на «a/b» или со словом «bastyon» отвергается; сохранение «О себе» со старым именем проходит.
- [ ] Настройки → Система: тумблер автозапуска совпадает с системой после выключения автозапуска в настройках ОС.

- [ ] Отказы ноды словами: упереться в дневной лимит постов, комментариев или оценок — видна причина («Вы достигли лимита…»), а не «Не удалось опубликовать». Оценка сверх лимита больше не пропадает молча.
- [ ] Платная видимость: у автора с ценой платной подписки пункт «Платные подписчики» есть, у остальных нет; правка поста для платных подписчиков его сохраняет.
- [ ] Превью ссылок: у постов со ссылкой в ленте карточка с заголовком и картинкой; «Предпросмотр ссылок» в настройках убирает карточки и в ленте, и в композере; под Tor картинка карточки грузится по нажатию.

## IPFS в десктопе

- [ ] Установка: клик по `ipfs://`-ссылке → согласие → прогресс скачивания. «Отменить установку» посреди скачивания останавливает его сразу: недокачанный архив удалён, нода выключена, ссылка открылась через публичный шлюз, следующий клик снова спрашивает согласие. Установка без сети заканчивается «Ошибкой» в меню IPFS, а после перезагрузки окна не крутится вечно.
- [ ] Первый запуск ноды: `ensure` с авторизацией API проходит. На Apple Silicon Kubo запускается (нет `Killed: 9`), `codesign -dv` на его бинаре показывает ad-hoc-подпись. На Windows SmartScreen и антивирус не блокируют `kubo.exe`.
- [ ] Окно просмотра: картинка, видео (перемотка работает), PDF (macOS и Windows — в окне, Linux — сохранение), сайт с `index.html`. Окно `incognito`, со страницы не уйти на чужой сайт. Через публичный шлюз в заголовке окна `dweb.link`.
- [ ] Сохранение: zip по ссылке → нативный диалог → файл совпадает с оригиналом и с локальной ноды, и без неё (через публичный шлюз, тогда он проверен по CID). Пока файл качается, рядом лежит `<имя>.part`; после ошибки его нет.
- [ ] Публикация на странице «Мои файлы» (меню аккаунта или меню IPFS): «Поделиться файлом» и «Поделиться приватно» открывают нативные диалоги; файл появляется в списке; ссылка публичного файла содержит имя и открывается в браузере; приватная на другом компьютере расшифровывает и сохраняет файл.
- [ ] «Перестать раздавать»: файл пропадает из списка, `ipfs pin ls` его не показывает. Тот же файл, опубликованный вторым аккаунтом этого устройства, у него остаётся в раздаче. Удаление аккаунта с устройства снимает с раздачи его файлы.
- [ ] Чат: 📎 → «Файл через IPFS» → нативный диалог → в чате карточка с именем и размером. Собеседник в браузере жмёт «Скачать» — файл скачивается и расшифровывается; на десктопе «Раздавать дальше» закрепляет файл, он появляется в его «Моих файлах» с пометкой «получен, раздаю». Файл больше 512 МБ — вопрос «отправить по ссылке»; обычное вложение больше 25 МБ — предупреждение с подсказкой про IPFS.
- [ ] Большой приватный файл (1–2 ГБ): публикация идёт без роста памяти приложения; на другом компьютере «Скачать» → окно «Скачано … из …», файл совпадает с оригиналом; «Отменить» посреди обрывает и не оставляет файла. В браузере тот же файл скачивается потоком (Chrome пишет на диск по мере скачивания).
- [ ] Несколько файлов разом: в «Моих файлах» все в списке и тост с числом, в чате — по карточке на файл.
- [ ] Со сторонним pinning-сервисом: у свежей публикации статус «копируется на сервис» сменяется на «сохранён на сервисе»; у файла, опубликованного до подключения сервиса, работает «Сохранить на сервисе»; «Перестать раздавать» удаляет копию и на сервисе.
- [ ] Удалённый pin с настоящим сервисом (Pinata или ipfs-cluster): endpoint и токен → «Поделиться файлом» → CID появился у сервиса.

Длительности, кривая и точка роста проверены по вычисленным стилям, но движения на снимках не видно.
- [ ] Синий логотип рядом с зелёным акцентом тёмной темы на реальном экране. Логотип — фирменный градиент, его не перекрашиваем; на снимках с акцентом не спорит.

## Видеоплеер: клавиши

Пробел, рамка фокуса, иконка по центру, зажатые клавиши и полный экран проверены в Chromium и
WebKit (Playwright). Не проверены Firefox и живые сборки.

- [ ] Firefox: запустить ролик, нажать кнопку звука мышью, затем пробел — ролик встаёт на паузу, звук второй раз не переключается. Firefox нажимает кнопку в фокусе при отпускании пробела; это отпускание глушит менеджер плееров.
- [ ] Десктоп (Tauri: WKWebView, WebView2, WebKitGTK): зажатый пробел переключает паузу один раз, зажатая стрелка перематывает плавно, без рывков по 30 раз в секунду. Защита держится на `KeyboardEvent.repeat` — проверить, что движки его ставят.
- [ ] Safari и Tauri на macOS: полный экран по F и двойному клику, пробел в полном экране, Esc выходит; после выхода другие ролики ленты на месте.
