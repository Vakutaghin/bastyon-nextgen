# v0.1.0 — Первый публичный релиз NextGen

Это первый релиз нового клиента **Bastyon NextGen** — переписанной версии интерфейса с фокусом на децентрализацию, скорость и self-custody.

## Что внутри

- **Лента и посты** — топовая лента, иерархическая лента, профильная лента; полноценные карточки постов с видео, изображениями, тегами и комментариями.
- **Комментарии** — древовидное обсуждение, голоса, ответы, моментальные обновления.
- **Мессенджер** — сквозное шифрование (E2E) групповых чатов, поиск по контактам, кэш профилей.
- **Кошельки** — баланс, история транзакций, отправка PKOIN, связка адресов с Block Explorer.
- **Block Explorer** — встроенный обозреватель блоков, транзакций, адресов и пиров.
- **Tor** — опциональная маршрутизация трафика через Tor в десктоп-сборке.
- **Профиль** — карточка профиля, лента автора, переход по адресу.

## Новое в этом релизе

- **Поиск по Бастиону.** В шапке появилась строка поиска с быстрым выпадающим списком (пользователи / теги / посты) и отдельной страницей `/search` с табами и постраничной подгрузкой. Посты в результатах отрисовываются теми же карточками, что и в ленте.
- **Окно «Что нового».** Появилась эта самая модалка — открывается один раз после установки новой версии и доступна в `Настройки → Что нового`. Записи на русском и английском хранятся в репозитории в папке `changelogs/`.
- **Выбор языка.** В `Настройки → Общие` появился переключатель языка (RU/EN). Пока влияет только на тексты changelog — постепенно расширим на весь интерфейс.

## Под капотом

- TanStack Query как универсальный кэш-слой для RPC-запросов к ноде.
- Pinia для состояния, lazy-роуты для код-сплита, styled-components для тем.
- IndexedDB как локальный персистентный слой (настройки, история, кэш).

## Принципы

- **Только мнемоника** — никаких SSO и посредников. Ключи остаются у пользователя.
- **Standalone** — приложение должно работать как самостоятельный клиент, без обязательной связки с другими сервисами.
