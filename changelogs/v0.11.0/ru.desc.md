# v0.11.0 — Видео сжимается без установки FFmpeg, «Мои видео» показывают все ролики

Чтобы сжать видео перед загрузкой, больше не нужно ставить FFmpeg самому: приложение скачает модуль сжатия, когда вы попросите. «Мои видео» показывают ролики со всех видеосерверов, а ссылку IPFS можно просто вставить в поиск. Если у вас на компьютере 0.9.4 или новее, эту версию поставит кнопка «Обновить» (кроме пакета .deb).

## Сжатие видео

- **Модуль сжатия вместо установки FFmpeg.** Раньше видео сжималось, только если FFmpeg установлен в системе. Теперь его скачивает само приложение: кнопка **«Скачать модуль сжатия»** в окне загрузки или «Настройки» → «Общие» → «Модуль сжатия видео». Видео загружают не все, поэтому модуль не встроен в приложение, а скачивается один раз: от 36 до 56 МБ в зависимости от системы. Приложение сверяет каждый файл с размером и контрольной суммой, зашитыми в него. Если включён Tor, модуль скачивается через Tor. FFmpeg из системы тоже подходит, если в нём есть кодек H.264 (x264).
- **Сжимается, только когда это поможет.** Если сжатие уменьшит файл меньше чем на пятую часть, например видео уже сжал мессенджер, оно загружается как есть, без лишнего ожидания. Видео, которое сжать не получилось, тоже загружается как есть. Окно загрузки пишет, почему видео ушло без сжатия.
- **Сжимаются и файлы больше 500 МБ.** Раньше такие файлы загружались без сжатия. Теперь предел другой: сжатый файл не больше 1 ГБ, это примерно полчаса в 1080p.
- **Копий на компьютере больше нет.** Раздел «Сжатые на этом компьютере» хранил копию каждого сжатого видео. Загруженный ролик и так лежит на сервере, а «Повторить» берёт сжатый файл из самой загрузки, так что копии только занимали место. После обновления они удаляются.

## Мои видео

- **Видны ролики со всех видеосерверов.** Список брал ролики только с тех серверов, которые сейчас принимают загрузки. Ролики, загруженные раньше, лежат на десятках других серверов и в список не попадали: у одного аккаунта из 20 роликов были видны 2. Теперь приложение находит их по вашим постам с видео и показывает вместе с остальными, новые сверху. Ролик со старого сервера, которого нет ни в одном посте, приложение пока найти не может.
- **«В посте» без перезагрузки.** Пока пост с роликом ждёт блока, у ролика написано «Публикуется». Когда пост попадёт в блок, надпись сама сменится на «В посте».
- **Пост открывается прямо отсюда.** **«Открыть пост»** показывает пост в окне. Если ролик есть в нескольких постах, кнопка «Посты: 2» откроет список с датами и подписями.
- **Шапка компактнее.** «Обновить» стал значком рядом с «Загрузить видео», заголовка «На видеосервере» больше нет.

## IPFS

- **Ссылку IPFS можно вставить в поиск.** Вставленная в строку поиска ссылка `ipfs://…` или `ipns://…`, адрес на шлюзе (с `https://` или без) или просто CID открывается сразу, как при нажатии на ссылку в посте. Набранная руками — по Enter. Приватная ссылка открывается вместе с ключом.
- **«Открыть IPFS-браузер».** В приложении для компьютера в меню значка IPFS появилась своя адресная строка. Вставьте ссылку и нажмите «Открыть»: содержимое откроется в окне просмотра. Под строкой — «Недавние», последние 8 адресов. Приватные ссылки туда не попадают: в них ключ от файла.

## Интерфейс

- **Разделитель в меню слева** между «Обсуждаемое» и «Сервисы»: ленты выше, сервисы, эксплорер и справка ниже.
