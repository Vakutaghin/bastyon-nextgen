# v0.13.5 — Монеты прежнего «Кошелька», ники в уведомлениях, фильтр групп

Дополнительные кошельки снова те же, что «Кошелёк» в прежнем приложении Bastyon, и монеты на них снова видно. В уведомлениях вместо адресов ники, в мессенджере появился фильтр групп, а приложение ставится на телефоны с 32-битным Android и запускается из AppImage на Fedora. Если у вас на компьютере 0.9.4 или новее, эту версию поставит кнопка «Обновить» (кроме пакета .deb). На телефоне с 0.12.0 тоже работает «Обновить», с более ранней версии поставьте эту вручную.

## Кошелёк

- **Монеты из «Кошелька» прежнего приложения снова видно.** С версии 0.3.0 это приложение выводило **«Дополнительные кошельки»** не из ключа аккаунта, как прежнее приложение Bastyon, а из фразы восстановления. Адреса получались другие, и монеты, лежавшие в «Кошельке» прежнего приложения, здесь пропадали из баланса. Теперь это снова те же десять адресов, и их монеты входят в общий баланс.
- **Адреса прежних версий не теряются.** Если на адресе, который выдавали версии с 0.3.0 по 0.13.4, есть монеты, он тоже стоит в таблице, с подписью **«Адрес прежней версии этого приложения»**.
- Тратить с дополнительных кошельков приложение пока не умеет, они только для просмотра. Потратить эти монеты можно в прежнем приложении Bastyon.

## Уведомления

- **Ник вместо адреса.** Почти все уведомления приходят только с адресом отправителя, и приложение показывало адрес, даже когда уже загрузило профиль. Теперь видны ник и аватар. Уведомления, пришедшие при открытом списке, тоже получают ник сразу, а не после повторного открытия.
- **Пока ник и аватар грузятся,** на их месте серая строка и серый круг.

## Мессенджер

- **Фильтр групп.** Над списком чатов теперь **«Все»**, **«Личные»**, **«Группы»** и **«Каналы»**, в большом мессенджере и в виджете. Последние три включаются, как флажки, в любом сочетании, а если включить все три, снова будет **«Все»**. Прежний выбор **«Переписки»** превращается в **«Личные»** и **«Группы»**.

## Профиль

- **Новый аватар не возвращается к старому.** Пока транзакция с правкой профиля не попала в блок (обычно около минуты), нода отдаёт прежний профиль. Приложение при следующем запросе показывало старый аватар и имя, и казалось, что аватар не сменился. Теперь новые аватар и имя держатся, пока транзакция не подтвердится.
- **Картинку, которую не открыть, видно сразу.** Если выбрать для аватара файл, который приложение не может открыть (например, HEIC с камеры телефона), появится **«Не удалось открыть картинку. Выберите JPG, PNG или WebP»**.

## Установка

- **APK ставится на телефоны с 32-битным Android.** С версии 0.8.0 в APK была только 64-битная часть, и телефоны с 64-битным процессором, но 32-битным Android (Redmi 9A и другие недорогие) писали, что приложение несовместимо с устройством. Теперь в APK есть обе.
- **AppImage запускается на Fedora.** AppImage вёз с собой графические библиотеки Wayland из Ubuntu 22.04. На Fedora с новой Mesa они не сходились с системными, и окно оставалось пустым. Теперь их в AppImage нет, берутся системные.
- **Установщики первыми в списке файлов релиза.** GitHub показывает только первые десять файлов, и установщик для Windows прятался под «Show all». Служебные файлы, которые скачивает само приложение, теперь начинаются с `_` и стоят в конце списка.

## Остальное

- **Значок IPFS — глобус.** В шапке вместо галочки глобус: серый, когда модуль выключен, и зелёный, когда работает.
- **Кнопка закрытия мини-приложения видна целиком.** Справа вверху из-за края выглядывала узкая полоска, и крестик был виден не полностью. Теперь крестик виден всегда, а подпись **«Закрыть»** выезжает при наведении.
