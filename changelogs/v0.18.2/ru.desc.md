# v0.18.2 — Локальное хранилище снова работает

Исправление после 0.18.0 для тех, кто ставил приложение давно. Если у вас на компьютере 0.9.4 или новее, эту версию поставит кнопка «Обновить» (кроме пакета .deb). На телефоне с 0.12.0 тоже работает «Обновить», с более ранней версии поставьте эту вручную.

## Исправления

- **«Локальное хранилище недоступно» при каждом запуске.** Если приложение стояло с ранних версий, с 0.18.0 оно не могло обновить свою базу на устройстве. Поэтому не сохранялись настройки, избранное, уведомления и позиции просмотра. Теперь при первом запуске приложение само переносит всё это в новую базу и работает как обычно.
- **«Что нового» открывалось при каждом запуске** по той же причине. Теперь — один раз на версию, даже если база на устройстве недоступна.
