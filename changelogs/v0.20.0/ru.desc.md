# v0.20.0 — Без VPN: напрямую к нодам

Если прокси Bastyon у вашего провайдера заблокированы (так сейчас почти по всей России), приложение для компьютера и Android само подключится к нодам блокчейна напрямую — без VPN. Если у вас на компьютере 0.9.4 или новее, эту версию поставит кнопка «Обновить» (кроме пакета .deb). На телефоне с 0.12.0 тоже работает «Обновить», с более ранней версии поставьте эту вручную.

## Подключение к сети

- **Ноды напрямую.** Обычно приложение ходит в сеть через прокси Bastyon. Если ни один не отвечает, оно подключается к нодам блокчейна само: лента, профили, комментарии, кошелёк и уведомления работают как раньше. Как только прокси снова ответят, приложение вернётся на них.
- **Выбор в настройках.** «Настройки» → «Система» → **«Подключение к сети»**: **«Авто»** (так по умолчанию), **«Прокси»** или **«Ноды напрямую»**. Под переключателем написано, чем идут запросы сейчас и сколько нод на связи.
- **Шифрование.** Соединение с нодой шифруется. Сертификат ноды приложение запоминает при первом подключении и не пользуется нодой, если сертификат потом сменился. Баланс кошелька сверяется у нескольких нод.
- **Что учесть.** Нода видит ваш IP-адрес. Регистрация, переводы постов и превью ссылок без прокси не работают; картинки и видео загружаются. В браузере прямого подключения нет, а с включённым Tor всё идёт через Tor, как раньше.
- **Ещё один прокси** — pre.pocketnet.app: он доступен и из России.
