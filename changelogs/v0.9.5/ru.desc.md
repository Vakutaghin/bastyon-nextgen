# v0.9.5 — Запускается там, где раньше не открывалось

Версии 0.9.0–0.9.4 для Mac на Apple Silicon не запускались, если на Mac не установлен Homebrew. На Windows без пакета Visual C++ приложение тоже не открывалось. Это исправлено. Кроме того, приложение теперь работает на macOS 10.15 и там, где встроенный браузерный движок старый. Если у вас 0.9.4 на компьютере, эту версию поставит кнопка «Обновить» (кроме пакета .deb).

## Компьютер

- **Mac на Apple Silicon.** Версии 0.9.0–0.9.4 закрывались сразу после запуска, если на Mac нет Homebrew: приложение искало одну из его библиотек. Теперь ему хватает того, что есть в macOS. Если прошлые версии у вас не открывались, поставьте эту вручную со страницы релиза на GitHub.
- **Windows без пакета Visual C++.** Приложение не запускалось, а система писала, что не найден MSVCP140.dll. Теперь всё нужное — внутри приложения, отдельный пакет Microsoft Visual C++ Redistributable не нужен.
- **macOS 10.15.** На Intel-Mac с macOS 10.15 окно приложения оставалось пустым. Теперь приложение работает с Safari 15 — последней версией для 10.15. Обновить Safari можно в «Системных настройках» → «Обновление ПО».
- **Windows 8.1** официально не поддерживается, но приложение может на ней работать, если установлены обновления системы и Microsoft Edge WebView2.

## Старые движки

- **Чаты на старых движках.** На движках старее Safari 17.4 и Chrome 119 в чат не отправлялись картинки и файлы, а после обрыва связи чаты переставали обновляться до перезапуска. Так было на macOS 11, Windows 8.1 и Android со старым Android System WebView. Исправлено.
- **Если движок совсем старый,** вместо пустого окна появляется экран «Приложение не запустилось» с подсказкой, что обновить: Safari, Android System WebView или Microsoft Edge WebView2.

## Справка

- В «Установке» — что делать, если приложение не запускается: на macOS 10.15, на Windows с ошибкой про MSVCP140.dll и на Android.
