# The app and settings

Which devices Bastyon NextGen runs on, how the versions differ, and how to set the app up the way you like.

## Where it runs

Bastyon NextGen exists for computers — macOS, Windows and Linux — and for Android phones. There is no iPhone app or web version with a public address yet; how to install the app is in [Installing the app](install.md).

Your account, posts, subscriptions, coins and chats are stored on the network, not on the device. So you see the same things on any device — all you need is your [recovery phrase](recovery-phrase.md).

## How the versions differ

The feed, posts, profiles, wallet, chat, mini apps and help work the same everywhere. What differs is whatever needs programs on the computer itself:

| | Computer | Android |
| --- | --- | --- |
| [Tor](tor.md) | yes | no |
| Sharing files over [IPFS](ipfs.md) | yes | no |
| Opening IPFS links | yes | yes |
| [Voice input](voice-input.md) | yes | no |
| [Compressing a video](video-compression.md) before upload | yes | no |
| Interface scale and autostart | yes | no |
| Tray icon | Windows and Linux | no |

On the phone, on the other hand, videos and audio keep playing while the app is in the background — see [The phone app](mobile-app.md).
