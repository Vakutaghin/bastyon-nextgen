# Language and appearance

How to change the interface and feed language, the theme, the scale and animations.

## Language

Change the language in the header — next to the logo, where the flag and the language name are — or in **“Settings”** → **“General”** → **“Language”**. There are nine languages: Russian, English, German, French, Spanish, Italian, Serbian, Korean and Chinese.

The interface language is also the feed language: the app passes it to the node, which picks posts, tags and recommendations in that language. To read posts in another language, switch the interface language. See [Feed](feed.md).

The help exists in Russian and English. With any other interface language it opens in English.

## Theme

**“Settings”** → **“General”** → **“Theme”**:

- **“Auto”** — follows the device’s system: if the dark theme is on there, it is dark here too;
- **“Light”** or **“Dark”** — always that one.

To switch quickly, use the sun or moon button in the header.

## Scale

In the desktop app: **“Settings”** → **“System”** → **“Interface scale”** — from 80 to 150%. Ctrl and + or − change the same scale by the same steps, and Ctrl+0 returns to 100% (Cmd on a Mac). A pinch on the touchpad does not change the scale. In a browser, the browser itself handles the scale.

## Animations

**“Settings”** → **“System”** → **“Animations”** — smooth transitions in the interface. Turn them off if the app feels sluggish or the animations bother you.
