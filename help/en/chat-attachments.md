# Photos, videos and files in chat

What you can send in a chat, how large it can be, and how to send a big file.

## Attaching

Press **“Attach”** — the paper clip to the left of the input field:

- **“Photo”** — pictures, several at once if you like;
- **“File”** — any file, videos included;
- **“File via IPFS”** — for big files, in the desktop app, see below;
- **“Send PKOIN”** — a transfer right in the conversation, see [Sending PKOIN in a chat](pkoin-in-chat.md).

You can also drag files into the chat window or paste them from the clipboard.

While a file uploads, it shows how many percent have been sent. The recipient sees pictures and videos right in the conversation, and a file gets a **“Download”** button.

## Size limit

- a picture — up to 100 MB;
- a file or a video — up to 25 MB.

The chat server will not accept anything larger, and the app tells you straight away. A big file can go through IPFS: in the desktop app, **“Attach”** → **“File via IPFS”**, see [Files over IPFS in chat](ipfs-in-chat.md).

## Encrypted attachments

Photos, videos, files and voice messages are encrypted on your device before they are sent: each file has its own random key, and that key is encrypted for the chat members. The server stores only the encrypted file, and only the people it was sent to can open it. More in [Message encryption](chat-encryption.md).
