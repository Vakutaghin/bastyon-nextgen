# Chats

How to start a conversation, find a chat or a message, delete a conversation or hide someone’s messages.

## Starting a chat

You start a conversation with someone from their profile — the **“Start chat”** button — or with the chat button next to their name in a post header. A card with the person opens: name, reputation, followers and following. Press **“Start chat”** under it and write the first message.

The messenger has no people search of its own: find the person by name with [search](search.md).

If someone new writes to you, the chat with them appears in the list by itself.

## The chat list

Each chat shows the other person’s name and avatar, the start of the last message (**“You:”** if you wrote it), the time and the number of unread messages.

The three-dot button on a chat is **“Delete dialog”**. The app asks again: **“Delete dialog?”** You leave the conversation, and it disappears from your list. The other person keeps it, and if either of you starts a chat again, it will be a new conversation.

## Search

The **“Search in conversation…”** field is at the top of an open chat. It searches the messages that are already loaded: to find an old one, scroll the conversation up first — earlier messages load as you scroll.

## Group chats

Group chats created in the previous Bastyon app are visible here too: you can read and write in them. This app cannot yet create groups, invite or remove members. PKOIN can be sent only in private chats.

Group messages use a simpler encryption scheme than private ones — see [Message encryption](chat-encryption.md).

## An unpleasant contact

- **“Hide messages”** is the ⊘ button next to the conversation search. It works in the chat only.
- **“Block”** in the person’s profile goes further: it removes them from your feeds and from the chat.

More in [Blocking](blocking.md).
