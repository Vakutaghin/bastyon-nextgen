# Keyboard shortcuts

Key combinations for help, scale, video and dictation.

On a Mac, press Cmd instead of Ctrl.

## Everywhere

| Key | What it does |
| --- | --- |
| F1 | help on the current screen — the article opens at the side, see [Using this help](using-help.md) |
| Esc | close a window; in the chat, go back to the list, then close the messenger; finish dictation |

## Scale

In the desktop app, Ctrl and + or − enlarge and shrink the whole window — the same as **“Interface scale”** in the settings, see [Language and appearance](appearance.md). In a browser these keys change the browser’s own zoom.

## Text

| Where | Key | What it does |
| --- | --- | --- |
| chat message | Enter | send |
| chat message | Shift+Enter | new line |
| comment | Ctrl+Enter | send; when editing, save |
| mention with @ | ↑ and ↓, Enter | pick a person from the list |
| post tags | Enter, comma or space | add a tag |
| any field | Ctrl+Z | undo typing, dictated text included |

## Video

The keys act on the video in full screen, or if there is none, on the one playing or started last. Until you have started any video, Space scrolls the page.

| Key | What it does |
| --- | --- |
| Space or K | play and pause |
| ← and → | back and forward 5 seconds |
| J and L | back and forward 10 seconds |
| 0–9 | to a part of the clip: 0 is the start, 5 the middle |
| ↑ and ↓ | volume |
| M | sound on/off |
| F | full screen |
| Shift + > and Shift + < | faster and slower |
| Shift + ? | list of keys |

More in [Watching videos](video-player.md).
