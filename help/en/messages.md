# Messages

How to write, reply to and react to messages, delete them, and tell whether a message was delivered.

## Writing

Type in the **“Type a message...”** field and press Enter or the send button. Shift+Enter starts a new line. The smiley button opens emoji. In the desktop app you can dictate the text — see [Voice input](voice-input.md).

A link to a Bastyon post turns into a card: the author, a picture and the start of the text, and a click opens the post. Links to other sites get no card in an encrypted conversation: building one would mean showing the link to a server.

To send a photo, a file or a voice message, see [Photos, videos and files in chat](chat-attachments.md) and [Voice messages](voice-messages.md).

## Replies and reactions

- The three-dot button on a message is **“Actions”**. **“Reply”** — your reply will quote the original message; above the input field you see what you are replying to, and the cross cancels the reply.
- The smiley button on someone else’s message is **“Reaction”**: 👍 ❤️ 😂 😮 😢 🙏. Reactions show under the message with a count.

## Deleting

In the **“Actions”** menu of your own message — **“Delete”**. The app asks again: **“Delete message?”** The message is deleted for everyone in the chat.

A sent message cannot be edited.

## Was it delivered

- **✓✓** next to the time means **“Seen”**: the other person opened the conversation and saw the message.
- “typing…” above the input field means the other person is typing.
- **“Not sent”** means the message did not go out, for example the connection dropped. The text stays on screen: press **“Retry”**.

## Message notifications

When a message arrives in a chat that is not open, a sound plays and the unread count on the chat icon goes up. If **“Browser notifications”** are on in the [notification settings](notifications.md) and the app window is minimised, the system tells you too — without the text: the sender’s name and what arrived, for example “New message” or “Image”.
