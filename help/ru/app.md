# Приложение и настройки

На каких устройствах работает Bastyon NextGen, чем отличаются версии и как настроить приложение под себя.

## Где работает

Bastyon NextGen есть для компьютеров — macOS, Windows и Linux — и для телефонов на Android. Приложения для iPhone и веб-версии с общим адресом пока нет; как установить приложение — в статье [Установка приложения](install.md).

Аккаунт, посты, подписки, монеты и чаты хранятся в сети, а не на устройстве. Поэтому на любом устройстве вы увидите одно и то же — нужна только [фраза восстановления](recovery-phrase.md).

## Чем отличаются версии

Лента, посты, профили, кошелёк, чат, мини-приложения и справка устроены одинаково везде. Отличается то, для чего нужны программы на самом компьютере:

| | Компьютер | Android |
| --- | --- | --- |
| [Tor](tor.md) | есть | нет |
| Делиться файлами через [IPFS](ipfs.md) | есть | нет |
| Открывать IPFS-ссылки | есть | есть |
| [Голосовой ввод](voice-input.md) | есть | нет |
| [Сжатие видео](video-compression.md) перед загрузкой | есть | нет |
| Масштаб интерфейса и автозапуск | есть | нет |
| Значок в трее | Windows и Linux | нет |

На телефоне зато видео и аудио продолжают играть, когда приложение свёрнуто, — см. [Приложение для телефона](mobile-app.md).
