# Фото, видео и файлы в чате

Что можно отправить в чат, сколько это может весить и как передать большой файл.

## Прикрепить

Нажмите **«Прикрепить»** — скрепку слева от поля ввода:

- **«Фото»** — картинки, можно сразу несколько;
- **«Файл»** — любой файл, в том числе видео;
- **«Файл через IPFS»** — для больших файлов, в приложении для компьютера, см. ниже;
- **«Отправить PKOIN»** — перевод прямо в переписке, см. [Перевод PKOIN в чате](pkoin-in-chat.md).

Файлы можно и просто перетащить в окно чата или вставить из буфера обмена.

Пока файл загружается, под ним видно, сколько процентов отправлено. У получателя картинки и видео показываются прямо в переписке, а у файла — кнопка **«Скачать»**.

## Предел размера

- картинка — до 100 МБ;
- файл или видео — до 25 МБ.

Файл больше этого чат-сервер не примет, и приложение скажет об этом сразу. Большой файл можно передать через IPFS: в приложении для компьютера — **«Прикрепить»** → **«Файл через IPFS»**, см. [Файлы через IPFS в чате](ipfs-in-chat.md).

## Шифрование вложений

Фото, видео, файлы и голосовые шифруются на вашем устройстве ещё до отправки: у каждого файла свой случайный ключ, а сам ключ зашифрован для участников чата. На сервере лежит только зашифрованный файл, и открыть его может лишь тот, кому он отправлен. Подробнее — [Шифрование переписки](chat-encryption.md).
