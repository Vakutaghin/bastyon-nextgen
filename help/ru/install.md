# Установка приложения

Где скачать Bastyon NextGen для компьютера и телефона и как установить его на macOS, Windows, Linux и Android.

## Какой файл скачать

- Страница релизов на GitHub; таблица файлов — как в `.github/release-body.md` (Apple Silicon и Intel, Windows x64, AppImage и .deb, Android 7+).
- Как узнать процессор Mac: меню Apple → «Об этом Mac».

## macOS

- Перетащить в «Программы». Первый запуск macOS заблокирует: приложение не нотаризовано → «Конфиденциальность и безопасность» → «Всё равно открыть».
- «Приложение повреждено» → команда `xattr -dr com.apple.quarantine`.
- Запросы доступа к микрофону и камере: для голосовых сообщений, голосового ввода и входа по QR-коду.

## Windows

- Файл .msi; SmartScreen: «Подробнее» → «Выполнить в любом случае».

## Linux

- AppImage — сделать исполняемым; .deb — через `apt install`. **Проверить:** какая библиотека нужна для значка в трее.

## Android

- Разрешить установку из этого источника.
- APK подписан отладочным ключом: перед новой версией старую нужно удалить — а с ней удалятся и ключи на телефоне. Сначала убедиться, что фраза записана.

## Без установки

- Версия для браузера и чем она ограничена — в статье [Приложение и настройки](app.md). **Проверить:** публичный адрес веб-версии.
- iPhone: **проверить**, есть ли сборка.
