# Файлы через IPFS в чате

Как отправить собеседнику файл любого размера и помочь раздавать полученный файл.

## Отправить

Обычное вложение в чате ограничено 25 МБ. Файл больше можно передать через IPFS — в приложении для компьютера:

1. **«Прикрепить»** → **«Файл через IPFS»**.
2. Выберите файл — можно сразу несколько: каждый уйдёт отдельным сообщением.

Пока файл публикуется, видно **«Публикую файл в IPFS…»**. Файл отправляется приватно: он шифруется на вашем компьютере, а ключ уходит в самом сообщении — переписка зашифрована, и ключ видят только участники чата. Предела размера нет.

Файл раздаёт ваш компьютер, пока открыт Bastyon, и он появляется в ваших [Моих файлах](my-files.md). Если вы закроете приложение раньше, чем собеседник скачает файл, он получит его, только когда вы снова откроете Bastyon или файл начнёт раздавать кто-то ещё. Круглосуточно файл будет доступен, если подключён [сервис хранения](ipfs-remote-pin.md).

## Получить

Файл приходит карточкой: имя, размер, **«приватный, через IPFS»** и кнопка **«Скачать»**. Скачать его можно в любой версии приложения: на компьютере, в браузере и на телефоне. В браузере и на телефоне действуют пределы размера — см. [Как открыть IPFS-ссылку](open-ipfs-links.md). В списке чатов такое сообщение видно как «📎» и имя файла.

Если у собеседника прежнее приложение Bastyon, он увидит вместо карточки ссылку `ipfs://…`.

## Раздавать дальше

На карточке чужого файла в приложении для компьютера есть кнопка **«Раздавать дальше»**. Ваш компьютер скачает файл и станет ещё одним его источником: файл будет доступен, даже когда отправитель не в сети. В сети при этом будет видно, что ваш компьютер его раздаёт.

Файл появится в [Моих файлах](my-files.md) с отметкой **«получен, раздаю»**, а на карточке — **«Раздаётся»**. Перестать — на странице **«Мои файлы»**: **«Перестать раздавать»**.
