# Хранение на сервисе

Как сделать, чтобы ваши файлы были доступны, даже когда компьютер выключен: подключить сервис удалённого pin.

## Зачем

Ваши файлы доступны, пока их раздаёт ваш компьютер. Сервис удалённого pin хранит их копии и раздаёт круглосуточно. Своего такого сервиса у Bastyon нет: подключается сторонний, с вашей учётной записью на нём.

Подойдёт любой сервис, который поддерживает IPFS Pinning Service API, например:

- Pinata — адрес API `https://api.pinata.cloud/psa`;
- Filebase — адрес API `https://api.filebase.io/v1/ipfs`;
- ipfs-cluster на вашем собственном сервере.

У сервисов обычно есть бесплатный объём, а за большее берут плату — условия смотрите на их сайтах.

## Подключить

1. Зарегистрируйтесь на сервисе и получите в его личном кабинете токен доступа.
2. Откройте [Мои файлы](my-files.md) и нажмите **«Подключить сервис…»**.
3. Введите адрес API сервиса — он должен начинаться с `https://` — и токен. Нажмите **«Сохранить»**.

С этого момента новые файлы, которыми вы делитесь, копируются на сервис сами. Адрес и токен хранятся в [модуле IPFS](ipfs-module.md) на этом компьютере; если удалить модуль, сервис придётся подключить заново.

## Статусы

Рядом с файлом в списке видно, что с его копией:

- **«в очереди на сервис»** и **«копируется на сервис»** — сервис забирает файл с вашего компьютера. Не закрывайте Bastyon, пока копирование не закончится; статус обновляется сам;
- **«сохранён на сервисе»** — копия готова, файл доступен и при выключенном компьютере;
- **«сервис не сохранил файл»** — чаще всего сервис не застал компьютер в сети или на нём кончилось место. Нажмите **«Сохранить на сервисе»**, чтобы попробовать снова.

Файлы, которыми вы поделились до подключения сервиса, и полученные из чата сами на него не копируются: у них та же кнопка **«Сохранить на сервисе»**.

## Отключить

**«Мои файлы»** → **«Настройки сервиса…»** → **«Удалить сервис»**. Копии, которые уже лежат на сервисе, при этом остаются — удалить их можно в личном кабинете сервиса.

А **«Перестать раздавать»** у файла при подключённом сервисе удаляет и его копию на сервисе.
