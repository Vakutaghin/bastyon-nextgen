# Хранение на сервисе

Как сделать, чтобы ваши файлы были доступны, даже когда компьютер выключен: подключить сервис удалённого pin.

## Подключить

- **«Мои файлы»** → **«Подключить сервис…»**: адрес API и токен доступа. Какие сервисы подходят (Pinata, свой ipfs-cluster) — **проверить** на живом сервисе.

## Статусы

- В очереди, копируется, сохранён, не сохранил; **«Сохранить на сервисе»** для старых файлов.

## Отключить

- **«Удалить сервис»**; **«Перестать раздавать»** удаляет и копию на сервисе.
