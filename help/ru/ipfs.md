# Файлы и IPFS

Как делиться файлами любого размера без облака: файл раздаёт ваш компьютер, а получатель проверяет, что пришёл именно он.

## Что такое IPFS

[IPFS](glossary.md#ipfs) — сеть для обмена файлами. Файл в ней находят не по адресу сервера, а по отпечатку его содержимого — CID, и раздают его все, у кого он есть, как в торренте. Ссылка на файл выглядит как `ipfs://…` и содержит этот отпечаток. Поэтому по ссылке нельзя подсунуть другой файл: скачивая его, приложение сверяет со ссылкой каждую часть.

Своего хранилища у Bastyon нет: файлы никуда не загружаются, их раздаёт тот, кто ими поделился.

## Что умеет Bastyon

- **Открывать IPFS-ссылки** — в приложении для компьютера, в браузере и на телефоне. См. [Как открыть IPFS-ссылку](open-ipfs-links.md).
- **Делиться файлами** — только в приложении для компьютера: раздавать файлы может лишь программа IPFS на вашем компьютере, см. [Модуль IPFS](ipfs-module.md). Поделиться можно по ссылке или приватно — см. [Мои файлы](my-files.md), — а можно отправить файл собеседнику прямо в чат: [Файлы через IPFS в чате](ipfs-in-chat.md).

## Пока файл кто-то раздаёт

Файл доступен, пока его раздаёт хотя бы один компьютер:

- ваш — пока на нём открыт Bastyon;
- тех, кто получил файл и нажал **«Раздавать дальше»**;
- сервиса хранения, если вы его подключили, — см. [Хранение на сервисе](ipfs-remote-pin.md).

Если никого из них нет в сети, файл не найдётся, и приложение скажет: **«Файл не нашёлся в сети. Скорее всего, тот, кто им поделился, сейчас не в сети. Попробуйте позже.»**

Тот, кто раздаёт файл, в сети виден: по ссылке можно узнать IP-адреса компьютеров, которые его раздают.

## IPFS и Tor

Если в приложении для компьютера включён [Tor](tor.md), IPFS не работает совсем — ни открыть ссылку, ни поделиться файлом. Окно просмотра и программа IPFS ходят в сеть напрямую, мимо Tor, и раскрыли бы ваш IP-адрес. Приложение покажет окно **«Включён Tor»**. Чтобы воспользоваться IPFS, выключите Tor.
