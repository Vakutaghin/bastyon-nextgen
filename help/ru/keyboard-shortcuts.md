# Горячие клавиши

Сочетания клавиш для справки, масштаба, видео и диктовки.

## Везде

- F1 — справка по текущему экрану; Esc — закрыть окно или остановить диктовку.

## Масштаб

- Ctrl и + / − (на Mac — Cmd): масштаб интерфейса в приложении для компьютера. **Проверить** Ctrl+0.

## Видео

- Таблица клавиш плеера: воспроизведение, звук, полный экран, скорость, перемотка на 10 секунд, громкость, `?` — подсказка. **Проверить** по `consts.ts`.

## Сообщения

- **Проверить**: отправка по Enter, перенос строки.
