# Мои файлы

Как поделиться файлом по ссылке или приватно и следить, что раздаёт ваш компьютер.

## Где

- Меню аккаунта → **«Мои файлы»** или значок IPFS в шапке. Состояние ноды: работает, остановлена, не установлена — **«Запустить»**.

## По ссылке

- **«Поделиться файлом…»**: ссылку откроет любой, у кого она есть. Можно выбрать несколько файлов.

## Приватно

- **«Поделиться приватно…»**: файл шифруется, ключ — только в ссылке. Без полной ссылки файл не прочитать.

## Список

- Метки **«по ссылке»**, **«приватный»**, **«получен, раздаю»**; **«Скопировать ссылку»**, **«Перестать раздавать»**. Список свой у каждого аккаунта.

## Когда компьютер выключен

- Файл скачают только у тех, кто уже раздаёт его. Круглосуточно — [Хранение на сервисе](ipfs-remote-pin.md).
