# Мои файлы

Как поделиться файлом по ссылке или приватно и следить, что раздаёт ваш компьютер.

## Где

Меню аккаунта → **«Мои файлы»**, или значок IPFS в шапке → **«Мои файлы»**. Страница есть только в приложении для компьютера; в браузере на ней написано, что делиться файлами можно лишь там.

Вверху видно, раздаёт ли компьютер файлы сейчас:

- **«Нода IPFS работает: файлы раздаются, пока открыт Bastyon.»**;
- **«Нода IPFS остановлена: сейчас файлы никому не раздаются.»** — нажмите **«Запустить»**;
- **«Модуль IPFS не установлен: он установится при первой публикации.»** — см. [Модуль IPFS](ipfs-module.md).

## Поделиться по ссылке

Нажмите **«Поделиться файлом…»** и выберите файл — можно сразу несколько. Приложение опубликует его и скопирует ссылку в буфер обмена. Откроет файл любой, у кого есть ссылка, — на компьютере, в браузере или на телефоне.

Имя файла входит в ссылку: его и тип файла увидит каждый, кому ссылка попадёт.

## Поделиться приватно

**«Поделиться приватно…»** — файл шифруется на вашем компьютере, и в сеть уходит только шифр. Ключ есть лишь в самой ссылке, после знака `#`, и в сеть не отправляется. Прочитать файл сможет только тот, у кого ссылка целиком. Имя файла тоже спрятано в ссылке.

Ссылку можно переслать дальше, как любую другую: кому бы она ни попала, он откроет файл. Передавайте её так, чтобы не увидели посторонние, — например, в [чате](ipfs-in-chat.md): переписка зашифрована.

## Список

У каждого файла — имя, размер, дата и отметка: **«по ссылке»**, **«приватный»** или **«получен, раздаю»** — это файлы, которые вы начали раздавать из чата кнопкой **«Раздавать дальше»**.

- **«Скопировать ссылку»** — снова взять ссылку на файл.
- **«Перестать раздавать»** — компьютер больше не будет раздавать файл. Кто уже скачал его, может раздавать дальше, поэтому удалить файл из сети насовсем нельзя.

Список свой у каждого аккаунта: другой аккаунт на этом компьютере не видит ваших файлов и ключей к приватным. Когда вы выходите из аккаунта, его файлы перестают раздаваться.

## Когда компьютер выключен

Файлы раздаются, пока на компьютере открыт Bastyon. Когда он выключен, файл можно скачать только у тех, кто уже раздаёт его. Чтобы файлы были доступны круглосуточно, подключите сервис хранения — см. [Хранение на сервисе](ipfs-remote-pin.md).
