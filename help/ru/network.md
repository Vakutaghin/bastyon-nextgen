# Сеть и ноды

К каким серверам подключается приложение, как оно выбирает ноду и где посмотреть состояние соединения.

## Публичные ноды

Всё, что вы видите и делаете в Bastyon, — посты, профили, оценки, кошелёк — идёт через [ноды](glossary.md#нода) сети. Само приложение с нодами не соединяется: оно подключается к прокси Bastyon 1.pocketnet.app … 6.pocketnet.app, а прокси передаёт каждый запрос одной из нод своего пула. При запуске приложение проверяет все прокси разом, берёт первый живой по списку и работает с ним, пока он отвечает. Перестал отвечать — приложение само переключится на другой.

Свою ноду для всего приложения указать нельзя: выбрать ноду можно только для [блокчейн-обозревателя](explorer.md). А вот помочь сети своей нодой можно — см. [Публичная нода для Bastyon](node-public.md).

Кроме нод, приложение ходит к серверам чата [Matrix](glossary.md#matrix), к серверам [видео](video.md) PeerTube, а в приложении для компьютера — ещё к GitHub за [обновлениями](updates.md).

## Что приходит сразу

С нодой открыто постоянное соединение. По нему сразу приходят:

- новые блоки — в [блокчейн-обозревателе](explorer.md) горит отметка live;
- транзакции с вашим адресом: так ваш пост или комментарий перестаёт быть «ожидающим», как только сеть его подтвердит, а под вашим открытым постом сами появляются новые комментарии.

Остальное приложение проверяет само: [уведомления](notifications.md) — раз в 30 секунд, новые посты в ленте — раз в полторы минуты, и тогда над лентой появляется кнопка «Показать новые посты».

## Состояние соединения

**«Блокчейн-обозреватель»** → вкладка **«Сеть»** → **«Подключение и прокси»** — что с соединением прямо сейчас:

- путь запроса: **«Устройство»** — есть ли интернет и идёт ли связь через [Tor](tor.md), **«Прокси»**, через который работает приложение, **«Нода»**, которая подготовила последний ответ, и сколько он занял. Путь обновляется с каждым ответом: прокси выбирает ноду на каждый запрос, поэтому нода меняется;
- какие прокси Bastyon отвечают, сколько приложений к ним подключено и сколько нод у каждого в пуле.

Там же — карта всей сети нод, см. [Блокчейн-обозреватель](explorer.md#сеть-карта-нод). Версия приложения и проверка обновлений — в **«Настройки»** → **«Что нового»**.

Блоки в сети выходят примерно раз в минуту. Если последний блок в шапке обозревателя давний, нода отстала от сети, и свежие посты и переводы появятся с задержкой. Если связи нет совсем, см. [Нет связи с сетью](connection-problems.md).
