# Настройка pocketcoin.conf

Где лежит файл настроек ноды, какие порты она открывает и какие параметры стоит знать.

## Где файл

Настройки ноды — текстовый файл `pocketcoin.conf` в папке данных:

| Система | Папка данных |
|---|---|
| Linux | `~/.pocketcoin` |
| Windows | `%APPDATA%\Pocketcoin` |
| macOS | `~/Library/Application Support/Pocketcoin` |
| Docker | папка, которую вы подключили к `/home/pocketcore/.pocketcoin` в контейнере |

Сам файл нода не создаёт — создайте его. Каждая строка — параметр командной строки без дефиса: `-dbcache=2048` в файле пишется как `dbcache=2048`. Строки с `#` — комментарии. После правки ноду нужно перезапустить.

Другую папку данных задают параметром `-datadir=<путь>`. Тогда его же нужно передавать и `pocketcoin-cli`.

## Порты

| Порт | Что это | Открывать наружу |
|---|---|---|
| 37070 | связь нод между собой | да, если хотите входящих соединений и публичную ноду |
| 37071 | RPC управления: кошелёк, остановка, все команды | **никогда** |
| 38081 | публичный API — его спрашивают прокси Bastyon | для публичной ноды |
| 8087 | WebSocket: новые блоки и транзакции для прокси | для публичной ноды |
| 38881 | публичный API по TLS | для публичной ноды, желательно |
| 8887 | WebSocket по TLS | для публичной ноды, желательно |
| 38082, 38083 | статические ресурсы и REST, обычно выключены | нет |

TLS на портах 38881 и 8887 работает с сертификатом, который нода создаёт сама, без проверки домена. Прокси Bastyon по умолчанию ходят на обычные порты 38081 и 8087, а в режиме «только TLS» — на 38881 и 8887.

> [!CAUTION]
> Порт 37071 даёт полный доступ к ноде и её кошельку. В старых инструкциях встречается `rpcallowip=0.0.0.0/0` — так открывать нельзя: пароль RPC передаётся без шифрования, а подобрать или перехватить его — дело времени.

## Нода для стейкинга

Нода, которая только хранит монеты и выпускает блоки, обходится почти без настроек: стейкинг и кошелёк включены по умолчанию.

```
# Принимать команды pocketcoin-cli
server=1

# Публичный API не нужен: нода не обслуживает пользователей
api=0

# Больше памяти под кэш базы — быстрее синхронизация
dbcache=1024

# Отключать ноды старых версий, застрявшие на своей ветке
disconnectold=1
```

Пароль RPC прописывать не нужно: `pocketcoin-cli` на той же машине входит по файлу `.cookie`, который нода сама создаёт в папке данных при каждом запуске.

## Публичная нода

Команда выкладывает пример настроек рядом со снапшотами — [pocketcoin.conf.example](https://snapshot.pocketnet.app/pocketcoin.conf.example). Его основа:

```
server=1

# Несколько живых нод для начала
addnode=65.21.56.203
addnode=135.181.196.243
addnode=178.217.159.221

# Управление — только с этого сервера
rpcbind=127.0.0.1
rpcallowip=127.0.0.1

# Потоки и очереди: управление — мало, публичный API и приём транзакций — много
rpcthreads=2
rpcworkqueue=10
rpcpublicthreads=30
rpcpublicworkqueue=3000
rpcpostthreads=15
rpcpostworkqueue=1500

# Публичный API и WebSocket: их спрашивают прокси Bastyon
api=1
publicrpcport=38081
wsport=8087

staking=1
disconnectold=1
logips=1
```

Номера портов здесь по умолчанию и записаны для наглядности: менять их не стоит, прокси ищут ноды только на стандартных портах. Если какой-то из адресов `addnode` перестал отвечать, ничего страшного: дальше нода найдёт соседей сама. Остальное — в статье [Публичная нода для Bastyon](node-public.md).

В примере есть ещё `wsuse=1` — нынешние версии ноды такого параметра не знают и пропускают его с предупреждением в журнале.

## Параметры, которые стоит знать

**Сеть**

- `listen=0` — не принимать входящие соединения от других нод. Исходящие нода открывает всё равно.
- `maxconnections=<n>` — сколько соединений с другими нодами держать, по умолчанию 125.
- `maxuploadtarget=<МиБ>` — сколько отдавать другим нодам в сутки. Пригодится на тарифах с лимитом трафика.
- `addnode=<адрес>` — подключиться к этой ноде и узнать от неё о других. Помогает, если нода не находит соседей.
- `externalip=<адрес>` — ваш публичный адрес, если нода сама его не определяет.
- `blocksonly=1` — получать только блоки, без пересылки транзакций; для первой синхронизации, см. [Первая синхронизация и снапшот](node-sync.md).
- `disconnectold=1` — отключаться от нод старых версий, которые после смены правил ушли на свою ветку. По умолчанию выключено, в официальном примере включено.
- `proxy`, `onlynet`, `listenonion` — работа через Tor; нода сама создаёт onion-адрес, если рядом запущен Tor с открытым управлением.

**Кошелёк и стейкинг**

- `disablewallet=1` — без кошелька. Стейкинга тогда нет.
- `staking=0` — кошелёк есть, но блоки нода не выпускает.
- `stakingrequirespeers=0` — стейкать, даже если нет соседей. Не включайте: без соседей нода выпустит блоки, которых никто не увидит.

**Доступ к RPC**

- `rpcauth=<пользователь>:<соль>$<хеш>` — логин и пароль для управления с другой машины. Строку делает скрипт `share/rpcauth/rpcauth.py` из репозитория ноды. Надёжнее, чем `rpcuser` и `rpcpassword`: пароль не лежит в файле открытым текстом.
- `rpcbind=<адрес>` и `rpcallowip=<адрес или подсеть>` — на каком адресе слушать RPC и с каких адресов пускать. Только локальная сеть или VPN.

**Производительность**

- `dbcache=<МиБ>` — кэш базы блоков, по умолчанию 450. Больше — быстрее синхронизация и проверка блоков, но больше памяти.
- `rpcthreads`, `rpcworkqueue` — потоки и очередь RPC управления; `rpcpublicthreads`, `rpcpublicworkqueue` — публичного API; `rpcpostthreads`, `rpcpostworkqueue` — приёма транзакций. По умолчанию 4 потока и очередь 16, у приёма транзакций — 2 потока. Для публичной ноды значения из официального примера в разы больше.
- `rpccachesize=<МБ>` — кэш ответов публичного API, по умолчанию 64.
- `sqltimeout=<секунд>` — сколько ждать тяжёлый запрос к базе соцсети, по умолчанию 10. Когда время выходит, клиент получает ошибку `sql request timeout`.
- `sqlcachesize=<МБ>` — кэш SQLite на одно соединение, по умолчанию 100.

**Журнал**

- `logips=1` — писать в журнал адреса нод.
- `debug=<категория>` — подробный журнал по категории, например `debug=net`. Журнал растёт быстро, включайте ненадолго.

Полный список — `pocketcoind -help`. Файл `share/examples/pocketcoin.conf` в репозитории ноды — старый шаблон от Bitcoin, на него лучше не опираться.

## Команды pocketcoin-cli

`pocketcoin-cli` отправляет команды запущенной ноде. В Docker — через `docker exec`, например `docker exec -it pocketnet.core pocketcoin-cli getblockchaininfo`.

| Команда | Что показывает |
|---|---|
| `getblockchaininfo` | высоту, идёт ли ещё первая синхронизация (`initialblockdownload`), сколько занимают блоки (`size_on_disk`, без базы соцсети) |
| `getnodeinfo` | версию, последний блок, вес стейкинга сети, порты |
| `getconnectioncount`, `getpeerinfo` | сколько соседей и какие |
| `getwalletinfo` | баланс кошелька, в том числе незрелые награды |
| `getstakinginfo` | идёт ли стейкинг и через сколько ждать блок |
| `getstakereport` | сколько кошелёк настейкал за сутки, 7, 30 и 365 дней |
| `stop` | правильно остановить ноду |
| `help <команда>` | справку по команде |
