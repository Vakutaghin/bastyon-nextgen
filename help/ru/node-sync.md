# Первая синхронизация и снапшот

Как новой ноде получить весь блокчейн: со снапшота — за несколько часов или сутки, с нуля — за несколько дней.

## Два способа

- **Со [снапшота](glossary.md#снапшот).** Команда Bastyon регулярно выкладывает архив с готовым блокчейном и базой соцсети на [snapshot.pocketnet.app](https://snapshot.pocketnet.app). Вы скачиваете его, распаковываете в папку данных, и нода догружает из сети только блоки, вышедшие после снапшота. Это быстро, и так советует README ноды.
- **С нуля.** Нода скачивает у соседей все блоки с 2019 года, проверяет каждый и заново строит базу соцсети. Это долго — несколько дней, а на медленном диске и больше недели, — зато вы ни на кого не полагаетесь. Официальная документация советует именно этот путь ради децентрализации.

<details>
<summary>Насколько можно доверять снапшоту</summary>

Снапшот готовит команда, и в нём уже проверенная кем-то история. Блоки, которые выйдут после снапшота, ваша нода проверит сама, а вот прошлое — нет. Подделать снапшот незаметно трудно: высоту и хеш последнего блока легко сравнить с [блок-эксплорером](explorer.md) и с любыми другими нодами, а подделанная цепочка разошлась бы с сетью на первом же новом блоке. Но ошибки бывают: в 2023 году один снапшот оказался с цепочкой на чужой ветке. Поэтому после запуска сверьте хеш последнего блока, а если нужна полная независимость — синхронизируйтесь с нуля.

</details>

## Со снапшота

На сервере хранятся пять последних снапшотов, новый появляется раз в 7–11 дней. Имя файла — высота блока, на которой сделан снимок, а `latest.tgz` — копия самого свежего. В конце октября 2026 года архив весит около 96 ГБ. Свободного места нужно и под архив, и под распакованные данные, которые в несколько раз больше, см. [Сервер для ноды](node-server.md).

1. Остановите ноду, если она уже запущена: `pocketcoin-cli stop`, в Docker — `docker compose stop`.
2. Если в папке данных уже есть кошелёк, скопируйте `wallet.dat` или папку `wallets/` и `pocketcoin.conf` в надёжное место.
3. Скачайте архив. `-c` позволит докачать, если загрузка оборвётся:

   ```
   wget -c https://snapshot.pocketnet.app/latest.tgz
   ```

   При скорости 100 Мбит/с это около двух с половиной часов, при 10 Мбит/с — почти сутки.

4. Проверьте, что архив скачался без ошибок:

   ```
   wget https://snapshot.pocketnet.app/sha256sum.txt
   sha256sum -c --ignore-missing sha256sum.txt
   ```

   Должно быть `latest.tgz: OK`. Если нет — докачайте или скачайте заново.

5. Удалите из папки данных старые базы — всё, кроме кошелька и настроек. Папка данных — та, где лежит `pocketcoin.conf`; в примерах это `/home/pocketcoin/.pocketcoin`, как в статье [Установка ноды](node-install.md):

   ```
   cd /home/pocketcoin/.pocketcoin
   sudo rm -rf blocks chainstate indexes pocketdb
   ```

6. Распакуйте архив в папку данных — это ещё десятки минут:

   ```
   sudo tar -xzf /путь/к/latest.tgz -C /home/pocketcoin/.pocketcoin
   ```

7. Проверьте владельца файлов: им должен быть пользователь, от которого работает нода. Для пакета — `sudo chown -R pocketcoin:pocketcoin /home/pocketcoin/.pocketcoin`, для Docker — `sudo chown -R 1000:1000 <папка данных>`.
8. Запустите ноду. Первый запуск долгий: нода строит индексы базы соцсети, которых нет в архиве, а потом догоняет блоки, вышедшие после снапшота. Это может занять несколько часов — в журнале при этом идут сообщения о базе, это не зависание.
9. Когда нода догонит сеть, сравните хеш последнего блока с [блок-эксплорером](explorer.md) и удалите архив.

На Windows папка данных — `%APPDATA%\Pocketcoin`, архив распаковывается любым архиватором, который понимает `.tgz`, например 7-Zip.

> [!TIP]
> Скачивать 96 ГБ лучше в `screen` или `tmux`: если SSH-соединение оборвётся, загрузка не прервётся.

## С нуля

Нода синхронизируется сама с первого запуска. Чтобы быстрее и с меньшим трафиком, README ноды советует на время первой синхронизации запустить её с параметрами:

- `-listen=0` — не раздавать блоки другим, пока сама не догнала;
- `-blocksonly=1` — загружать только блоки, без пересылки отдельных транзакций;
- `-disablewallet=1` — без кошелька.

Можно ещё поднять `dbcache`, например до 4096, если хватает памяти.

> [!IMPORTANT]
> Когда синхронизация закончится, уберите эти параметры: с ними нода не стейкает и не помогает сети.

## Как понять, что синхронизация закончилась

```
pocketcoin-cli getblockchaininfo
```

- `initialblockdownload: false` — первая синхронизация закончена;
- `blocks` равно `headers` — нода догнала всё, что знает о сети;
- высота совпадает с [блок-эксплорером](explorer.md).

Пока синхронизация идёт, нода не стейкает, а прокси Bastyon её не используют.
