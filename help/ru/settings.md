# Настройки

Все вкладки настроек по порядку: что в каждой и где об этом подробнее.

Настройки открываются из меню аккаунта — **«Настройки»**, на телефоне — из бокового меню. Они есть только после входа в аккаунт. Язык, тема и остальные параметры приложения общие для всех аккаунтов на устройстве.

## Общие

- **«Язык»** и **«Тема оформления»** — см. [Язык и оформление](appearance.md).
- **«Содержимое»**:
  - **«Показывать встроенные видео»** — проигрыватели YouTube и Vimeo прямо в посте; выключено — останется ссылка;
  - **«Автовоспроизведение видео»** — видео запускается, когда появляется на экране;
  - **«Предпросмотр ссылок»** — карточка с заголовком и картинкой под ссылкой;
  - **«Сортировка комментариев»** — в каком порядке открывается обсуждение, см. [Комментарии](comments.md);
  - **«Мессенджер»** — выключает чат целиком, см. [Мессенджер](messenger.md).
- **«Модуль IPFS»** — в приложении для компьютера, когда модуль установлен, см. [Модуль IPFS](ipfs-module.md).
- Голосовой ввод — в приложении для компьютера, см. [Голосовой ввод](voice-input.md).
