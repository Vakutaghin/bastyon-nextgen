# Сжатие видео

Как уменьшить большое видео на своём компьютере перед загрузкой в Bastyon.

## Где это

- Круглая кнопка в углу окна открывает **«Сжатие видео»**. **Проверить** значок и место.

## Нужен FFmpeg

- Приложение пользуется установленным в системе FFmpeg: macOS — `brew install ffmpeg`, Windows — `winget install ffmpeg`, Linux — пакетный менеджер.

## Как сжать

- Перетащить или выбрать файл → параметры исходного и целевого видео → **«Начать перекодирование»**.

## Готовые видео

- **«Сохраненные видео»**: посмотреть, **«Информация»**, **«Скачать»**, **«Удалить»**. Хранятся в приложении и занимают место; старые черновики удаляются сами.
- Готовый файл загружают в пост обычным способом — [Загрузка видео и аудио](video-upload.md).
