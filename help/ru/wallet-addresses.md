# Балансы и адреса

Основной и дополнительные кошельки, общий баланс и как получить PKOIN на свой адрес.

## Основной кошелёк

- Адрес аккаунта: на него приходят чаевые и переводы. **«Открыть в блок-эксплорере»**.

## Дополнительные кошельки

- **«Добавить кошелёк»** — до 20 адресов из той же фразы; **«Переименовать кошелёк»** — ярлык только на этом устройстве.
- Отправлять с них пока нельзя, только смотреть баланс; удалить нельзя — **проверить** формулировку «почему».

## Получить PKOIN

- **«Переводы»** → **«Получение»** → **«Показать адрес для получения»**: адрес, QR-код, **«Скопировать»**.
