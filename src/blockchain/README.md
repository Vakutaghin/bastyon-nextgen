# Blockchain module

Ключи, адреса, подписи, транзакции, хранение секретов и сессия аккаунта для
сети Pocketnet. Примеры использования — в тестах рядом с каждым модулем
(`*.test.ts`): они выполняются и потому не устаревают.

## Где что лежит

| Каталог | Что внутри |
|---|---|
| `core/keys/` | мнемоника (bip39, английский и русский словари), вывод ключей по пути `m/44'/0'/0'/N'`, восстановление из мнемоники / hex / WIF |
| `core/addresses/` | P-адрес (P2PKH) и Z-адреса доп. кошельков (P2SH), проверка адреса |
| `core/signatures/` | подпись для API прокси (`generateApiSignature`: nonce + срок 360 с) |
| `core/transactions/` | сборка транзакций (`build-*`), UTXO и их блокировки (`unspents-manager`), бродкаст (`transaction-sender`) |
| `core/actions/` | прикладные действия: пост, профиль, подписки и блокировки, жалоба, донат |
| `registration/` | транзакция регистрации (`user-info-tx`) — один путь и для модалки, и для досыла после перезагрузки |
| `api/` | капча, бесплатный баланс для регистрации, статус регистрации, подпись запросов |
| `storage/` | сейф секретов (`vault/`), список аккаунтов, ключи в разрезе аккаунта, незавершённая регистрация |
| `store/` | Pinia: `auth-store` (вход, смена аккаунта, выход, `resetForAccount`), `keys-store`, `profile-store` |
| `ws/` | WebSocket прокси: подписка на транзакции своего адреса |
| `lib/pocketnet/` | вендоренная библиотека старого клиента (форк bitcoinjs с `nTime`) — не править |

## Что нельзя сломать

- **Бродкаст — не повторяемая операция.** Всё, что уходит в сеть, идёт через
  `transaction-sender`: деньги — `sendTransactionWithMessage`, посты,
  комментарии, оценки и прочее — `broadcastTransaction`. Одна нода, длинный
  таймаут, «уже в mempool» = успех по локальному txid, после таймаута —
  проверка по txid, а не повторная отправка. Звать `sendrawtransactionwithmessage`
  напрямую нельзя: так появлялись двойные платежи и дубли постов.
- **Параметры сети — одни.** `constants/network.ts` обязан совпадать с сетью
  вендоренной библиотеки целиком; это проверяет тест.
- **WIF — только сети Pocketnet** (версия 0x21), как в старом клиенте.
- **Секреты хранятся только в сейфе.** Ключ устройства не извлекаем, по желанию
  поверх него — пароль. Старые записи (AES-CBC из `encryption.ts`) читаются
  только ради миграции, с проверкой правдоподобия (`vault/plausibility.ts`).
- **Всё, что относится к аккаунту, сбрасывается при его смене** —
  через `auth-store.resetForAccount` и `store/auth-store/account-scoped.ts`.
- **Входы транзакций — p2pkh основного адреса.** Трата с Z-адресов не
  реализована: приём на них скрыт, баланс только показывается.
